# Order template: Documentation (`docs`)

## Acceptance

- The documentation link check exits 0, and every referenced file, heading and command exists.

## Paths

- allow: docs/**
- allow: README.md
- allow: CHANGELOG.md

## Standing rules

- Keep prose, headings and formatting consistent with neighbouring documents (English, UTF-8 without BOM, LF line endings).
- Never include private paths, usernames, tokens or uninvented project names in documentation or examples.
